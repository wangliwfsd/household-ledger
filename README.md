# 家衡｜自托管家庭资产账本

家衡是一个适合电脑、手机和平板使用的家庭资产余额账本。它以“每个账户每月的月末余额”为核心，提供历史趋势、本月变化分析、账户管理、分期管理、房贷测算和 CSV 导出。数据保存在自己的 PostgreSQL 数据库中。

## 功能

- 按月录入 AUD/CNY 账户余额和月份备注
- 自动计算总资产、总负债、净资产和资产负债率
- 净资产趋势支持 3、6、12 个月和全部范围，悬停显示具体金额
- 本月账户贡献与分类贡献分析
- 分析页提供资产、负债、净资产三线趋势和分类堆叠趋势
- 可选择最多 5 个账户比较余额历史，图表月份可直达当月明细
- 历史月份快速浏览；确认后可修改历史数据
- 历史月份修改前自动创建快照，可查看差异并恢复旧版本
- 保存前进行金额、比例、汇率和净资产变化检查，只提醒、不阻止录入
- 新增、关闭、重新启用账户；关闭不删除历史
- 分期新增、编辑、删除、自动期数、已结清隐藏/查看
- “消费分期”账户自动同步未结清分期的剩余应付款
- 分期可标记“本期已进入信用卡余额”，仅扣除本期以避免重复负债，后续期数仍计入
- 房贷 Offset、还款增长率和逐月还款测算
- Excel 可打开的 UTF-8 CSV 导出
- Docker Compose 部署、自定义登录页与安全持久会话

## 数据规则

1. 账户关闭后不会出现在未来月份的录入中，过去记录保留。
2. 有历史余额的账户不能物理删除，只能关闭；没有历史的空账户允许安全删除。
3. 分期记录删除后不可在页面恢复，删除前会确认；消费分期余额随之重算。
4. “消费分期”是联动账户，不能在月度录入中手工覆盖。
5. 修改历史月份不会改变系统的当前月份，也不会改变账户启用状态。
6. CNY 余额按对应月份保存的汇率折算为 AUD；修改历史月份不会改动其他月份的汇率。

## 运行要求

- Docker Desktop 或 Docker Engine + Compose v2
- 建议至少 1 GB 可用内存
- 局域网或公网使用时建议配置 HTTPS 反向代理

## 首次启动

```bash
cp .env.example .env
```

修改 `.env`：

```dotenv
POSTGRES_PASSWORD=请设置高强度数据库密码
APP_USERNAME=family
APP_PASSWORD_HASH='$2b$12$这里填写生成的bcrypt哈希'
SESSION_SECRET=这里填写至少32个随机字符的会话密钥
AUTH_COOKIE_SECURE=true
```

登录密码不能明文写入 `.env`。先在已安装依赖的项目目录运行：

```bash
npm run auth:hash-password
```

终端不会显示输入的密码。把命令输出的整行复制到 `.env`。生成会话密钥可运行：

```bash
openssl rand -hex 32
```

通过 Cloudflare Tunnel 的 HTTPS 域名访问时，`AUTH_COOKIE_SECURE` 保持 `true`。如果暂时只通过 `http://192.168.x.x:3000` 调试，需设为 `false`，否则浏览器不会保存登录 Cookie。

启动：

```bash
docker compose up -d --build
```

打开 `http://localhost:3000`。局域网设备可访问 `http://电脑局域网IP:3000`。不要把 3000 端口直接暴露到公网；应使用 HTTPS 反向代理或安全隧道。

勾选“在此设备保持登录 30 天”后，会话会在活跃使用时自动续期，最长不超过 1 年；未勾选时关闭浏览器后 Cookie 失效。修改 `SESSION_SECRET` 可以立即让全部设备退出登录。

## 日常操作

### 新月份录入

进入“本月录入”，点击“录入下月”。新月份自动沿用上月余额，只需修改发生变化的账户、填写备注并保存。

### 历史修改

从“历史概览”点击月份进入明细，点击“修改此月”并确认。保存只更新该历史月份。

### 账户管理

- 新账户：点击“新增账户”。
- 关闭：点击账户行末尾的“关闭账户”。
- 查看关闭账户：点击顶部筛选按钮。
- 恢复：显示关闭账户后点击“重新启用”。

### 分期管理

当前期数按首期还款日自动推算。点击记录可编辑或删除；已结清记录默认隐藏但不会自动删除。新增、编辑或删除后，“消费分期”账户余额立即联动。

每条分期可设置“本期金额已包含在信用卡账户余额中”。勾选后，系统只从“消费分期”账户余额中扣除本期金额，未来剩余期数仍然计入；未勾选时，本期及未来期数全部计入。升级后此选项默认为未勾选，可在分期管理中根据实际账单逐条设置。

### 房贷计算

可修改贷款总额、利率、年限、当前余额、Offset、收入、总月还款和年度增长率。算法与源 Excel 一致：第 12、24、36…期应用年度还款增长，余额可由 Offset 全额覆盖时视为还清。

## 数据导出

进入“账户管理”，点击“导出数据”。生成的 CSV 包含全部月度账户余额、备注及对应月份汇率，可直接用 Excel 打开。

## 备份与恢复

数据库位于 Docker volume `ledger-data`。发布升级或批量修改前应备份：

```bash
docker compose exec -T db pg_dump -U ledger ledger > ledger-backup.sql
```

恢复会覆盖当前数据库，请先停止应用并确认备份文件：

```bash
docker compose stop app
docker compose exec -T db psql -U ledger -d ledger < ledger-backup.sql
docker compose start app
```

建议定期生成备份，并复制到另一块磁盘或加密云存储。

## 升级与维护

从旧版浏览器弹窗登录升级时，先在 `.env` 中删除旧的 `APP_PASSWORD`，按“首次启动”章节新增 `APP_PASSWORD_HASH`、`SESSION_SECRET` 和 `AUTH_COOKIE_SECURE`，再重建容器：

```bash
docker compose up -d --build
docker compose ps
docker compose logs --tail=100 app
```

容器启动时会自动执行 `db/migrations` 中尚未运行的数据库迁移，并把版本和校验值记录在 `schema_migrations` 表。迁移失败时应用不会启动，避免新代码使用未完成升级的数据库。已执行的迁移文件不可修改；后续结构变化应增加新的编号文件。

本地开发可手动执行：

```bash
npm run db:migrate
```

### 历史版本与恢复

修改历史月份并保存时，系统会先自动保存修改前的余额、汇率和备注。进入该月明细后点击“版本记录”可以查看逐账户差异并恢复。执行恢复前，系统还会自动保存当前版本，因此恢复操作也可以撤回。

保存任何月份前会检查异常变化并显示黄色提示，例如大额或大比例变化、负数余额、汇率突变、净资产突变，以及全部沿用但未填写备注。提示仅供确认，选择“数据无误，仍然保存”即可继续。

### 历史分析

“本月分析”页面支持 6、12、24 个月和全部时间范围，包含总资产/总负债/净资产三线趋势、资产负债分类堆叠趋势，以及最多 5 个账户的余额对比。CNY 账户按对应月份汇率折算为 AUD；点击任意月份的数据点或柱形可直接进入该月历史明细。

健康检查：

```bash
curl http://localhost:3000/api/health
```

## 发布前测试

项目的发布测试覆盖：鉴权、健康检查、历史数据、账户新增/关闭/启用/删除保护、分期新增/编辑/删除、消费分期联动、历史安全修改和 CSV 导出。

在应用运行且测试登录信息与 `.env` 一致时执行：

```bash
node ../work/release-test/final-release-test.mjs
```

测试使用临时账户和临时分期，并在结束前删除。正式发布前仍建议先执行数据库备份。

## 技术结构

- Next.js 16 / React 19
- PostgreSQL 17
- `postgres` 数据库客户端
- Docker Compose
- bcrypt 密码校验与签名会话 Cookie

主要接口：

- `/api/ledger`：月度余额、历史趋势和保存
- `/api/accounts`：账户新增、状态变更和安全删除
- `/api/installments`：分期、房贷参数和联动余额
- `/api/export`：CSV 导出
- `/api/health`：容器健康检查

## 安全提醒

- 首次发布前必须设置数据库密码、登录密码哈希和随机会话密钥。
- 登录连续失败 5 次后，同一来源与用户名会暂停尝试 15 分钟。
- 不要提交 `.env`、数据库备份或家庭财务导出文件。
- 公网访问必须使用 HTTPS。
- 定期测试备份能否恢复，而不只是确认备份文件存在。
